# Bare Sudoku

- Reklamsız, mümkün olan en küçük Android sudoku. Düz Java, kütüphane yok, Gradle yok, izin yok.
- Depo iki platform: `android/` (düz Java) ve `ios/` (C motor + Objective-C arayüz). Android derleme: `android/build.sh` (çıktı `android/build/baresudoku.apk`, boyut bayt olarak yazdırılır), test: `android/test.sh`.
- Sürüm: `bun run deploy` (scripts/deploy.sh) üçünü birden çıkarır: testler, ortak sürüm numarası (Android versionCode = iOS build numarası), APK + AAB + etiket + GitHub sürümü, Apple arşivleri ve yükleme, Play yükleme (scripts/play.js), App Store incelemeye gönderme (scripts/asc.js), web deploy (`../baresudoku-web`). `~/.baresudoku/asc.json` ve `~/.baresudoku/play.json` yoksa mağaza adımları "atlandı" diye geçer. `PLATFORMS="ios mac"` gibi Apple platformlarını seçer (varsayılan dördü). Sürüm notları `release-notes.json`. İmza anahtarı `~/.baresudoku/` altında, yedeği Alp'te.
- Google Play: `bun run aab` (android/bundle.sh, bundletool `~/Library/Android/sdk/bundletool/bundletool.jar`, AAB jarsigner ile release.jks yükleme anahtarıyla imzalanır). Mağaza metinleri `android/store/listing.json` (`bun scripts/play.js listing` yükler), anket cevapları metadata.md, ikon, tanıtım görseli ve 1080x1920 ekran görüntüleri `android/store/`. İlk AAB Play Console'a elle yüklenir.
- Apple: tek Xcode projesi, iki hedef: BareSudoku (iPhone, iPad, Mac Catalyst, visionOS; `Mac.entitlements` App Sandbox), BareSudokuTV (tvOS, `Info-tv.plist`, `Assets-tv.xcassets` katmanlı ikon + top shelf + launch image; kumanda imleci `handlePress:`/`moveCursor:`). Klavye: rakam, ok, Backspace, N/U/F/H, Esc. Ekran görüntüleri uygulama içinden: `-DSELFTEST` derlemesi, `BARESUDOKU_SELFTEST=demo` ve `BARESUDOKU_SHOTS=<klasör>` (simülatörde `SIMCTL_CHILD_` önekiyle); Mac'te pencere 1280x800'e sabitlenir. `ios/test.sh` (C testleri), `ios/build.sh sim` (simülatör), `bun run ipa` (imzalı IPA, yüklemeden), `bun scripts/asc.js metadata <sürüm> [ios|mac|tv|vision]` (ios/store/listing.json metin ve ekran görüntülerini App Store Connect'e yükler). Xcode projesi `ios/BareSudoku.xcodeproj`, otomatik imza takım 9X2XU3N96X, bundle com.baresudoku. Takımda kayıtlı cihaz olmadığı için arşiv CODE_SIGNING_ALLOWED=NO ile alınır, imza export'ta atılır. İkon tek kaynak `ios/icon.svg` (favicon), katalog derlemede üretilir; başka ikon boyutu eklenmez.
- Üç platformda aynı kurallar (giriş, baştan başla, notları doldur/temizle); web deposundaki engine.js ile birlikte değiştir.
- APK boyutu artırılmaz (24.972 bayt). Web sürümü ve 36 dil ayrı depoda: `~/Projects/baresudoku-web`, site baresudoku.com.
- Giriş kuralı (Game.key/Game.tap, Game.java + Game.c + web engine.js): tuş seçili boş hücreye yazar; yazacak yer yoksa ya da aynı tuşa ikinci basışta rakam kilitlenir ve dokunulan hücrelere yazılır, tekrar basınca çözülür. Kilitliyken hücre seçimi yoktur (dokunuş yazar, seçmez; sürükleme ve geri al seçmez), vurgu kilitli rakamı izler, ipucu kilidi açar.
